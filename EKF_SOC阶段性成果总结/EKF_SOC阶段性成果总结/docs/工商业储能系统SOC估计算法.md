## 1. 摘要

**一句话结论**：原有 SOC 方案（安时积分 + OCV 查表校准）在 LFP 平台期与待机工况下会失效，新方案采用 **4 状态偏置扩展卡尔曼滤波（EKF）** 进行全工况 SOC 估计，精度目标为 **SOC 误差 < 2%**（已实测达成：满充 1.79 点、满放 1.27 点）。

**新旧方案一句话对比**：原有方案是「库仑计数 + 多级电压修正」的传统查表法，电压信息在平台期几乎失效；新方案是「二阶 RC 等效电路模型 + 4 状态偏置 EKF」的状态估计法，把电流积分与端电压观测通过卡尔曼增益在线融合，并新增第 4 维偏置状态 `b` 在线吸收磁滞、极化欠估等系统性电压模型误差。

## 2. 背景与行业痛点

工商业储能系统大量采用磷酸铁锂（LFP）电芯，其 SOC 估计面临以下 5 条核心痛点：

1. **LFP 平坦 OCV-SOC 曲线（电压盲区）**：LFP 在 20%~85% 平台区 OCV 随 SOC 变化极小（dOCV/dSOC ≈ 0.015 V/SOC，SOC 为 0~1 分数），电压 1mV 的测量扰动即对应 ±0.7% 量级的 SOC 不确定度。平台区电压对 SOC 几乎无分辨力。
   → 二阶 RC ECM + EKF 融合电压与积分信息，并配 PCHIP 保单调 OCV 样条与斜率下限保护。

2. **磁滞效应（充放 OCV 差 10~30mV）**：同一 SOC 下充电与放电方向的 OCV 存在 10~30mV 差异，若用单一 OCV 曲线查表，会在充放切换时造成 SOC 跳变。
   → 新增偏置状态 `b` 在线吸收这类系统性电压偏差。

3. **稳压模式累计误差陷阱**：储能柜稳压模式（DCDC 打嗝 / 下垂环流 / 频繁充放切换）会破坏静置条件，使「静置 OCV 校准」无法触发，安时积分误差在无校准状态下持续累积。
   → 防发散校准（OCV 静置强校准 + 满充满放 + 容量在线更新）。

4. **容量衰减与 SOC 耦合**：额定/标称容量若长期不更新，会与真实可用容量产生系统性偏差（本项目为 314Ah 电芯，实测可用容量 ~287~289Ah，偏差约 8%，源于电芯老化与一致性差异），直接导致 SOC 系统性漂移。
   → 改用实际总容量 `Qn`（`GetGroupTotalCapAPI`）。

5. **静置不作为、充放电爆发**：待机/静置时微弱自放电电流低于采样死区阈值，库仑计「检测不到」，一旦突发充放电会以错误的 SOC 起点起跳，造成 SOC 高估/跳变。
   → 待机功耗建模（虚拟电流，方案预留）。

## 3. 原有 SOC 算法方案

### 3.1 原理

原有 SOC 本质是「**安时积分（库仑计数）+ 多级电压修正**」的传统方法：

```
SOC = 剩余可放电容量(nowCap) ÷ 总容量(topCap)
```

其中 `nowCap` 由**电流安时积分**得到，并叠加**温度修正、充放电末端电压步长修正、容量自动标定、SOC 平滑显示**等多级修正。

**（1）核心容量变量**（`t_CAPFORM`，1mAh 单位）：

| 变量 | 含义 |
| --- | --- |
| `nowCap` | 剩余可放电容量（安时积分累加） |
| `topCap` | 顶端容量 = 总容量（满充满放标定） |
| `baseCap` | 底端容量 = `CAP_ZERO_POINT`(1000000)，支持负容量 |
| `standCap` | 标称容量 |
| `remCap` | 剩余容量（另一套积分器） |

**（2）计算流程**（7 步）：

① **电流采样 + 安时积分**：分流器采样 10mA 单位，1ms 中断积分，带死区阈值（小电流不积分——这是实测库仑计比功率分析仪少计 2.7%~3.4% 的根源）。
② **容量积分**：`nowCap -= 净变化量`（放电减/充电加），100ms 周期，夹在 `[baseCap, topCap]`。
③ **真实 SOC 换算**：`soc = (nowCap - baseCap) × 1000 / (topCap - baseCap)`，千分之一。
④ **多级修正**（500ms）：温度修正（按平均温度查容量百分比表反推 SOC，偏差限幅 ±3%）+ 末端电压步长修正（y=kx+b 线性映射，充到截止电压 SOC→99.3%、放到截止 SOC→1.3%）+ 三者融合回写 `nowCap`。
⑤ **总容量自动标定**（1s）：满充满放时安时积分反推真实容量，加权平均 + 限幅（单次 +1%/-3%，收敛慢）。
⑥ **SOC 显示**（100ms）：末端修正（高压/低压保护强制 100%/0%）+ 平滑限速（5~120s 收敛，防突变）。
⑦ **SOH**：SOH = 当前总容量 / 额定容量。

**（3）关键参数**：

| 参数 | 值 | 含义 |
| --- | --- | --- |
| 末端修正目标 | 99.3% / 1.3% | 充电/放电截止电压对应的 SOC |
| 标定限幅 | +1% / -3% | 总容量单次修正上限 |
| 标定时长 | 10min ~ 60h | 满充满放有效时长范围 |
| 死区阈值 | DhgIntPoint/ChgIntPoint | 小电流不积分 |

### 3.3 三个致命局限

1. **电流精度累计误差**：积分带死区阈值，**小电流（CV 末段）不积分**，实测库仑计比功率分析仪**少计 2.7%~3.4%**。
2. **平台期无法校准**：LFP 20%~85% 平台区电压几乎不变，OCV 查表校准失效，只能靠纯积分，误差必然累积。
3. **满充满放损伤电池**：总容量标定需**完整满充满放**（单次修正限幅 1%~3%，收敛慢），频繁满充满放会加速电池老化。

### 3.4 基于电压/电流的 SOC 估计算法局限性总结

所有基于电压/电流的 SOC 估计算法，其信息源只有两类——**电压**与**电流**，各自都存在无法回避的固有局限。前文已述原有方案的三个具体致命问题（电流精度 / 平台期 / 满充满放），本节上升到「所有电压/电流法」的方法论共性局限，分四类归纳：

**（1）开路电压法（OCV 查表）**

- 需长时间静置、极化消除后才能测得准 OCV，不适合运行中的系统
- LFP 平台区 OCV 平坦，电压对 SOC 无分辨力
- 磁滞效应：充放电方向 OCV 差 10~30mV，单一曲线无法准确描述
- OCV 随温度漂移

**（2）安时积分法（库仑计数）**

- 累计误差：电流测量误差随时间积分放大
- 依赖初始值：必须已知初始 SOC 才能开始积分
- 依赖真实容量：老化后容量变化导致系统性偏差
- 电流死区/零点漂移：待机微弱自放电电流检测不到

**（3）基于电压的模型法（ECM + EKF/UKF/滑模/粒子滤波等）**

- 依赖模型精度：ECM 是集总简化模型，无法完全描述真实电化学过程
- 依赖参数辨识：R0/R1/C1/R2/C2 随 SOC/温度/老化剧变，离线辨识难覆盖全工况
- 平台区可观测性弱：dOCV/dSOC≈0 时，雅可比矩阵 H 的 SOC 分量≈0，电压观测对 SOC 的修正能力极弱
- 磁滞/极化建模难：需额外偏置状态或磁滞模型，增加复杂度

**（4）共同局限（所有基于电压/电流的算法）**

- 依赖传感器：电压/电流传感器失效或精度不足，算法即失效
- 平台区可观测性本质弱：LFP 平台区是物理特性，任何电压法都无法根本克服
- SOC 定义依赖容量：容量不准则 SOC 必然偏，无法独立于 SOH
- 静置/待机无信息输入：无电流时积分法无输入，电压又需静置才能测 OCV

## 4. 新 SOC 设计方案（4 状态偏置 EKF）

### 4.1 总体架构

新方案采用**三层结构**：

1. **安时积分基础层**：复用现有库仑计/安时积分作为 SOC 初始值与参考真值来源。
2. **滤波层（EKF）**：核心，4 状态偏置 EKF，把电流积分（状态方程）与端电压观测（观测方程）通过卡尔曼增益在线融合。
3. **校准层（预留 DQV）**：差分电压分析（dV/dQ）等离线/在线校准手段，用于对 OCV 曲线与容量做二次校准（**预留，未实现**）。

另预留**数据驱动二期**：以大数据/机器学习进一步优化参数与 SOC 估计。

![mermaid-04](images/mermaid-04.png)


### 4.2 核心算法

**二阶 RC 等效电路模型（ECM）**：

```
二阶 RC 等效电路（串联拓扑，放电电流 I 取正方向）：

   + ────[R0]────────[R1]─────────[R2]────────● Ut（端电压）
   |       |          |            |
  OCV      |         ─┴─          ─┴─
 (SOC)     |         ─┬─ C1       ─┬─ C2
   |       |          |            |
   − ──────┴──────────┴────────────┴───────────●

   R0      = 欧姆内阻      → 瞬时欧姆压降 I·R0（~0.2 mΩ 量级）
   R1/C1   = 快速极化支路   → 电化学电荷转移（秒~分钟级，τ1 = R1·C1）
   R2/C2   = 慢速扩散支路   → 锂离子浓差扩散（分钟~小时级，τ2 = R2·C2）
   OCV(SOC) = 开路电压    → 随 SOC 强非线性，PCHIP 样条查表
```


```
        R0          R1           R2
Ut = OCV(SOC) - I*R0 - U1 - U2   （U1/U2 为两级 RC 极化电压）
```

**五个参数物理含义**（配合上图）：

| 参数 | 物理含义 | 时间尺度 | 作用 |
| --- | --- | --- | --- |
| `R0` | 欧姆内阻（电解液/集流体/接触电阻） | 瞬时（毫秒~秒） | 产生瞬时压降 `I·R0`，反映内阻老化 |
| `R1` | 快速极化电阻（电荷转移） | 秒~分钟级 | 描述电流激励下的快速过电位 |
| `C1` | 快速极化电容（双电层/电荷转移） | 秒~分钟级 | 与 R1 构成快极化时间常数 `τ1 = R1·C1` |
| `R2` | 慢速扩散电阻（浓差极化） | 分钟~小时级 | 描述锂离子在固相中的扩散阻抗 |
| `C2` | 慢速扩散电容（浓差） | 分钟~小时级 | 与 R2 构成慢扩散时间常数 `τ2 = R2·C2` |

> 两级 RC 分别刻画「快速电化学反应」与「慢速浓差扩散」两类弛豫过程；`U1`、`U2` 即这两级 RC 支路的极化电压状态量，正是 EKF 中除 SOC 外的两个可观测状态。


离散化后得到状态空间模型，**状态向量**：

```
x = [SOC, U1, U2, b]^T
```

其中第 4 维 `b` 为**等效电压偏置状态**。源码注释（`ekf_bms.h`）对其定义：

> 「b 为慢时间常数的等效电压偏置，在线吸收 OCV/极化的系统性模型误差
> （如 LFP 充放电极化欠估 ~40mV、单体选择偏差等）」

即 `b` 用于在线补偿**磁滞、极化欠估、单体选择偏差**等一切「慢变」的系统性电压模型误差，避免这些系统性偏差直接污染 SOC 估计。

### 4.3 状态方程（Time Update / 预测）

```
soc_minus = soc_old - (eta * Ts / Qn) * I          # SOC 安时积分
phi1 = exp(-Ts / (r1 * c1));  g1 = r1 * (1 - phi1) # 一级 RC 离散化
phi2 = exp(-Ts / (r2 * c2));  g2 = r2 * (1 - phi2) # 二级 RC 离散化
u1_minus = phi1 * u1_old + g1 * I                  # 一级 RC 衰减 + 电流激励
u2_minus = phi2 * u2_old + g2 * I                  # 二级 RC 衰减 + 电流激励
b_minus  = b_old                                    # b 随机游走（转移系数 = 1）
```

- SOC 预测做物理边界钳位 `[0, 1]`。
- 协方差预测 `P_minus = A·P·A^T + Q`，状态转移矩阵 `A = diag(1, phi1, phi2, 1)`。
- `b` 的转移系数为 1（随机游走），配合极小的 `Q_b=1e-9`，使其只跟踪**分钟~小时级**的慢变化。

### 4.4 观测方程（Measurement Update / 更新）

```
Ut = OCV(SOC) + b - U1 - U2 - I * R0        # 观测方程（含偏置项 +b）
```

- 雅可比观测矩阵：`H = [d_ocv, -1, -1, +1]`，其中 `d_ocv = ∂OCV/∂SOC`，`∂Ut/∂b = +1`。
- 卡尔曼增益：`K = P_minus·Hᵀ / (H·P_minus·Hᵀ + R)`（标量除法）。
- 状态更新：`x = x_minus + K * error`，`error = Ut_measured - Ut_estimated`。
- 状态钳位：SOC 钳位 `[0, 1]`；`b` 限幅 `±bias_limit`（`bias_limit = 0.15 V`，即 ±150mV，防偏置发散吞掉 SOC 可观测性）。
- 协方差更新：`P = (I - K·H)·P_minus`，并做对称化（防单精度浮点累计误差发散）。

**EKF 关键设计点（b 偏置状态）**：

| 设计点 | 取值 | 设计意图 |
| --- | --- | --- |
| `b` 转移系数 | 1（随机游走，`b_minus = b_old`） | 偏置无动力学约束，靠观测方程 `+b` 逐步辨识 |
| `Q_b` | 1e-9（极小） | 只吸收「分钟~小时级」慢变系统误差（磁滞/极化欠估），不吞真实 SOC 的快速变化信息 |
| `bias_limit` | 0.15 V（±150mV） | 防止 b 发散到吞掉 SOC 可观测性的程度，限幅后偏置只能解释有限的系统电压偏差 |
| `P_b` 初值 | 1e-2（等效 ±100mV） | 放大 b 初始不确定度，允许滤波器初期快速收敛到真实偏置 |

> 一句话：`b` 是一个「慢、小、有限幅」的补偿状态——慢（Q_b 极小）、小（限幅 ±150mV）、有限幅（不会失控），专门吸收 OCV/极化模型无法覆盖的系统性电压偏差，而不抢走 SOC 本应占有的观测信息。

1. **HPPC 混合脉冲测试**：对电芯施加标准充放电脉冲，采集端电压/电流响应。
2. **NLS 双指数拟合**：取 1200s 弛豫窗口，用非线性最小二乘对脉冲响应拟合双指数曲线，分离出 R0/R1/C1/R2/C2 五参数。
3. **二维参数表生成**：按 SOC（5%~95%，10 格）× 温度（15~35℃，5 格）分充/放两套，生成离线参数表（`generate_ekf_params.py`）。
4. **运行时在线查表**：`EKF_GetBatteryParams` 用**二分查找**定位 SOC/温度所在网格区间，再**双线性插值**得到当前工况的精确参数值。

## 5. 新旧方案对比（★核心）

### 5.1 九维度对比总表

| 维度 | 原有方案 | 新设计方案 | 改进点 |
| --- | --- | --- | --- |
| 算法原理 | 安时积分（库仑计数）+ 多级电压修正（查表/步长） | 二阶 RC ECM + 4 状态偏置 EKF（状态估计融合） | 从「查表修正」升级为「模型+滤波」最优估计 |
| 平台期 SOC | 电压信息失效，纯积分累积误差 | OCV+极化模型融合，滤波层持续修正 | 平台区仍有滤波框架（但斜率极小仍是难题） |

| 容量处理 | 标称容量，需满充满放才标定，收敛慢 | 实际容量 `Qn = GetGroupTotalCapAPI`（异常回退标称） | 直接吃容量标定修正，消除 ~8% 积分漂移 |
| 校准方式 | 末端电压步长 + 温度查表 + 满充满放标定 | 电压观测在线校准 + DQV 离线校准（预留）+ 防发散校准 | 校准不依赖完整满充满放 |

| 模块化 | 紧耦合于 EnergyCalc/SocLib 状态机 | 独立 `SocEst` 模块 + 回调接口，影子模式低耦合 | 调用方零修改，可独立演进 |

## 8. 问题、难点与风险

1. **HPPC 数据质量**：RC 参数（R0/R1/C1/R2/C2）为实验室 HPPC 脉冲辨识结果，与实车连续工况（恒功率、间歇充放）存在外推偏差，影响模型精度。
2. **恒功率 vs 恒流差异**：辨识用恒流/脉冲，但储能实际常处恒功率工况，参数外推存在偏差。
3. **热待机无标准 OCV**：待机/静置时温度分布不均，无统一「标准 OCV」可用作校准基准。
4. **待机功耗非恒定需自适应**：自放电随温度/老化变化，固定虚拟电流不成立，需自适应建模（方案预留）。
5. **遗留 hack**：`EKF_GetOCVSlope` 中的斜率钳位 `if (slope < 0.005) slope = 0.005` 仍在（`ekf_utils.c`），平台区可能产生错误方向的强制修正。
6. **切换瞬态偏差（b 状态「凝固」）**：充放切换后偏置状态 `b` 无法快速重收敛（`Q_b=1e-9` 过小 → `P_bb` 收敛过深 → 增益 `K[3]` 极小），导致切换后过渡段偏差（1008 充电起点 +7.9 点、1009 放电 −4~−14 点）。待优化：分方向 b 状态（`b_chg`/`b_dis`）/ 切换时重置 `P_bb` / 切换后冻结电压更新。

### 8.1 影响 SOC 估计的其他关键因素

除上述痛点外，以下客观因素也持续影响 SOC 估计精度（容量衰减已从前文「SOC 耦合」角度讨论，此处从「电池老化」的内阻增大、自放电增大等维度补充）：

| 因素 | 影响机理 | 对 SOC 的影响 |
| --- | --- | --- |
| 温度 | 低温内阻剧增、OCV 曲线偏移、容量缩水、RC 时间常数变化 | 参数表/OCV 样条低温失效，SOC 偏差可达数 % |
| 电芯一致性 | 240 串电芯容量/内阻/自放电不一致 | 均值电芯法掩盖最差电芯，簇级 SOC 受木桶效应限制（三级 EKF 预留） |
| 电流测量精度 | 分流器采样 10mA 分辨率、零点漂移、死区阈值 | 安时积分误差随时间累积 |
| 电压测量精度 | ±3mV 采样精度 | 平台区 dOCV/dSOC≈0.015 V/SOC（分数）→ ±3mV 采样误差对应 SOC 不确定度 ±2.1% 左右 |
| 电池老化 | SOH 下降、容量衰减、内阻增大、自放电增大 | 参数表/容量需持续更新，否则系统性偏差 |

### 10.2 接口定义

```c
/* 输入结构体（3 字段） */
typedef struct {
    float I;            /* 回路电流 (A, 放电为正, 充电为负) */
    float Ut_measured;  /* 实测单体端电压 (V) */
    float temp;         /* 电池温度 (℃) */
} ekf_input_t;

/* 输出结构体（6 字段，含 bias） */
typedef struct {
    float SOC;          /* 估算 SOC (0~1) */
    float U1;           /* 一级 RC 极化电压 (V) */
    float U2;           /* 二级 RC 极化电压 (V) */
    float bias;         /* 偏置状态 b (V) */
    float Ut_estimated; /* 预测端电压 (V) */
    float error_Ut;     /* 残差 (V) */
} ekf_output_t;

/* EKF 实例结构体 */
typedef struct {
    float x[4];         /* 状态向量 x=[SOC,U1,U2,b]^T */
    float P[4][4];      /* 协方差矩阵 */
    float Q[4][4];      /* 过程噪声协方差 (Q[3][3]=Q_b) */
    float R;            /* 测量噪声协方差 */
    float Qn;           /* 额定容量 (As = Ah*3600) */
    float Ts;           /* 采样周期 (s) */
```
