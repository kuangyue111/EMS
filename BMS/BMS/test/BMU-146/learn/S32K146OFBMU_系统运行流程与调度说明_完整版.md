# 第一章：系统硬件与软件架构总览

## 1.1 硬件平台与核心器件

### MCU 核心

| 参数项 | 值 | 说明 |
|--------|-----|------|
| 型号 | NXP S32K146 | ARM Cortex-M4F (带 FPU) |
| Flash | 1 MB | 程序存储 + 内部 EEPROM 模拟 (4KB) |
| RAM | 128 KB | 全局变量 + FreeRTOS 堆栈 |
| 主频 | 80 MHz | PLL 倍频自 16MHz 外部晶振 |
| 开发工具 | Processor Expert 10.1 + S32 Design Studio | NXP 官方代码生成工具 |

### 关键外设与专用芯片

| 器件 | 接口 | 用途 | 关键参数 |
|------|------|------|----------|
| **NXP FS6503** | SPI0 | 安全系统基础芯片 (SBC) | 看门狗、电源(VAUX/VCAN/VCCA)、故障输出(FS0B/FS1B) |
| **ADI LTC6813** | SPI2 (菊花链) | 多串电芯监控 AFE | 12串/片, 最高 20 片菊花链 (240串), <1.2mV 精度 |
| **BF8915A** (备选) | SPI2 (菊花链) | 国产电芯监控 AFE | 16通道/片, 最高 20 片菊花链 |
| **ADI LTC2949** | SPI1 | 高压库仑计 | 电流/功率/能量/总压/温度 精确测量, 48位累加器 |
| **MCP3913** (备选) | SPI | 6通道电表 AFE | 备用电流/电压采集方案 |
| **SST26VF064** | SPI3 | 外部 SPI Flash | 8MB, 4KB 页/32KB 块擦除, 大容量数据记录 |
| **M24512** | I2C (模拟) | 外部 EEPROM | 64KB, 128B 页写入, 参数持久化 |
| **RX-8010SJ** | I2C (模拟) | 外部 RTC 时钟 | 高精度时钟, 内部 16B RAM |
| **KEA128** | SPI3 + GPIO | 从属 MCU | 分担采样功能, EWM 看门狗同步 |

### 通信通道物理配置

| 总线 | 物理层 | 波特率 | 用途 |
|------|--------|--------|------|
| CAN0 | 差分信号 | 500kbps | 外部通信 (上位机/PCS/CATL 协议) |
| CAN1 | 差分信号 | 500kbps | 从控板 (BSU/BMM) 通信 |
| CAN2 | 差分信号 | 500kbps | 外部通信 (充电机 GB/T 27930) |
| SCI0 (RS485-0) | 半双工, 19200bps | 19200 | Modbus RTU (上位机/HMI) |
| SCI1 (RS485-1) | 半双工, 19200bps | 19200 | Modbus RTU (辅助设备) |
| SCI2 (RS485-2) | 半双工, 19200bps | 19200 | Modbus RTU (预留) |
