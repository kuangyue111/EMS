## 实际模型

`ekf_bms.c:5-47`初始化四状态 `x=[SOC,U1,U2,b]`。电流放电为正，充电为负；Qn由Ah转As，Ts以秒计。电压偏置b初值0，限幅±0.15V。

预测关系（`ekf_bms.c:67-86`）：

```text
phi1 = exp(-Ts/(R1*C1)), phi2 = exp(-Ts/(R2*C2))
SOC- = SOC - eta*Ts*I/Qn
U1-  = phi1*U1 + R1*(1-phi1)*I
U2-  = phi2*U2 + R2*(1-phi2)*I
b-   = b
```

观测关系（`ekf_bms.c:115-145`）：

```text
Ut_est = OCV(SOC-,T,I) + b- - U1- - U2- - I*R0
residual = Ut_measured - Ut_est
H = [dOCV/dSOC, -1, -1, +1]
S = H*P-*H^T + R
K = P-*H^T/S
x = x- + K*residual
```

协方差采用 `(I-KH)P-`再对称化（162-185行），并非Joseph形式。SOC限制到[0,1]，S绝对值过小时设置下限。代码有这些保护，但没有因此证明任意输入下的正定性、有限性或数值稳定性。

## 参数与温度适用范围

RC参数以SOC 5%～95%、温度15～35℃的网格双线性插值；越界夹到边界，不做外推（`ekf_params.h:14-26`、`ekf_utils.c:41-76`）。OCV由SOC方向PCHIP三次系数和温度方向线性插值计算；SOC斜率下限0.005（`ekf_utils.c:93-169`）。充放电按电流正负切表，零电流选择放电表。

`ekf_params.h:7-9,26`默认CATL-285Ah-2，定义 `CELL_EVE_314`才选择EVE-314Ah-2。验证报告对象是EVE314Ah，因此复现实验必须保存编译宏和表版本；报告文字不能证明此份编译时采用了哪套表。

单体OCV模型使用平均电压时，估计对象接近等效平均单体；若切换到最高/最低电压，它对应的测量对象也改变。选压策略应与SOC定义、弱单体限制和端点校准共同验证，不能只凭RMSE改善就认定正确。

## 适配层行为

`EkfAdapterTask`固定Ts=0.5s；电池Ready后用现有SOC初始化、总容量mAh转Ah，容量为零时回退标称容量。它每次读取平均单体电压与平均温度，以分流器电流更新EKF，保存影子SOC并填充77/78/84索引数组。`refSoc`固定为0（`ekf_adapter.c:42-100`）。数组定义不等于CAN协议路由已经接通，需另外核对发送/查询表。

当前适配函数不回写旧算法的SOC、容量或保护状态。当前BMS的500ms槽只有空语句，因此独立包也不能视为已集成运行。

## 报告如何使用

测试报告v3.0日期为2026-10-09，称测试覆盖2026-09-04至10-09，最新充电RMSE1.79个SOC百分点。但其31-40行明确：REF_SOC无效，指标是相对BMS_SOC的偏差。它是两种估计的一致性指标，不是经过独立SOC真值验证的绝对误差。

原始日志、功率仪数据、参数辨识CSV、评估与画图脚本不在给定39文件包内，因此本轮不能独立复算精度或确认图像与源码版本匹配。报告中的切换后偏置收敛问题、限速改动和充放选压策略，作为历史实验信息保留；与交付代码不一致的部分见发现清单。

## 数值复核要点

`ekf_bms.c:41`的R=0.01进入S时被当方差使用；电压单位V时对应标准差sqrt(0.01)=0.1V，即100mV，与“约10mV”注释不一致。应核对标定依据与单位，不能未经实验直接把R改成某个经验值。

还需验证：Qn两级回退都无效时的处理、NaN/Inf输入、失效温度-41、Ready丢失、输入时序一致性、静置时切表跳变、偏置可观测性以及长时间协方差的稳定性。这些是验证待办，不是本轮已经证明发生的现场故障。
