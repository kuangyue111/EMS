# Knowledge-base maintenance

Read README.md, docs/04-findings.md and docs/06-coverage.md before answering project questions.
The source snapshot is a dated working-directory capture, not an attested deployed build.
Use index/knowledge.sqlite or tools/search.py to retrieve exact source and line numbers.
Distinguish indexed, manually reviewed, inferred, report-claimed and dynamically verified evidence.
The code graph attempts had extensive coverage gaps and were removed; do not claim a reliable call graph exists.
Preserve original source encodings and do not modify the original EMS directories when merely updating this knowledge base.
After source changes, rebuild the index and manually recheck affected findings. Existing notes may be stale.
The user's instructions determine whether to edit firmware or share externally; this knowledge base is not standing authorization to publish source code.
